# ひらがじゃん

Cloudflare Workers + Durable Objects + D1 で作るオリジナル麻雀「ひらがじゃん」。

## セットアップ

```bash
npm install
wrangler login
wrangler d1 create hiragajan-db   # 出力された database_id を wrangler.toml に反映
npm run db:init                   # スキーマ作成
npm run db:seed                   # サンプル単語投入(以後は words テーブルに随時INSERT)
npm run dev                       # ローカル起動
npm run deploy                    # デプロイ
```

単語の追加は `words` テーブルに `INSERT INTO words (word, han) VALUES ('たべもの', 1);` のように追加していくだけで、
GameRoom が起動時にD1から辞書を読み込みます。

## 実装済み

- ログイン/新規登録(Josiah Account): bcryptjsでパスワードハッシュ化しD1に保存、ユーザー名重複チェック・8文字以上チェック・確認一致チェック、remember meで保持期間を切り替え(30日 or ブラウザセッションのみ)
- ログイン成功後は `?redirect=` で指定された遷移先(未指定時は `index.html`)へ遷移。ゲーム画面(`/xiama/table`)など認証が必要なページは自動的に `login.html?redirect=...` へ誘導
- ホーム画面: 部屋作成・部屋参加・フレンド・プロフィール・オンライン人数(Lobby DOでWebSocketカウント)
- フレンド機能: 一覧・申請一覧・ID検索・申請・承認 (D1)
- 部屋作成: ルール設定(人数1-4/一局・東風・半荘・本荘/牌枚数2-8/持ち時間) → ランダム4桁部屋番号を`idFromName`で発行
- 部屋参加: 4桁番号存在チェック
- 待機画面: 準備OKで全員揃うと自動対局開始
- 対局画面(`/xiama/table` / GameRoom DO):
  - 77種牌(通常46・濁音半濁音26・小さい文字4・長音1)
  - サイコロ2回(裏)で親決定、手積み相当のシャッフル配牌、王牌5列(嶺上牌なし)
  - 配牌: 4枚×3周 → 親チョンチョン(2枚) → 残り1枚ずつ
  - ドラ表示牌の次の文字がドラ(循環)
  - 単語辞書のみでの手牌構成判定(雀頭・面子の区別なし)
  - 鳴き = 単語成立時の一律コール、下家>対面>上家の優先順位、捨て牌からの晒し方は単語の並び順+横向き
  - ロン優先、ダブロン・トリロン対応
  - リーチ・一発、四家立直での流局
  - 符計算: 基本25符、七対子相当(2文字単語×7)は一律25符、単語ごとに(文字数×2 or 特殊文字含めば×4)を加算
  - 飜計算: 単語ごとのDB登録飜 + リーチ + 一発 + ドラ
  - 満貫〜役満の点数区分、ロン/ツモの支払い計算、本場・親流れ

## 既知の簡略化・今後の拡張ポイント

- **持ち時間の実際のカウントダウン処理は未実装**(ルールとして保持しているのみ)。DOの`alarm`を使ったタイムアウト自動打牌の実装が必要。
- **牌のID管理がクライアント側では`kind`のみ**になっており、同種牌の個体識別をしていません。手牌を`{id, kind}`で送るよう拡張すると、UI上の牌の位置が安定します。
- **鳴きの複数候補同時発生時の優先順位再判定**は簡易実装です(`GameRoom.resolveCallPhase`にコメントで詳細記載)。全員のレスポンスが出揃った後、優先順位順に選び直すロジックの厳密な実装が必要です。
- **テンパイ/ノーテン判定による流局時の点数移動**は未実装(流局は通知のみ)。
- **裏ドラは実装済み(リーチ時のみ計上)**ですが、UI上での表示演出は簡易です。
- **フレンド招待の通知配信**(招待を受けた側にリアルタイム通知する仕組み)は未実装。現状は部屋番号を伝える形に留めています。
- **雀魂風のアニメーション・3D卓描画**は簡略化した2D CSSレイアウトです。演出の作り込みは別途。
- **GameRoomの状態はDO内メモリ保持が主**で、永続化は`persist()`で部分的にのみ行っています。DOがエビクトされた場合の対局復元は未対応です。
- ルール「一局/東風/半荘/本荘」の局数上限は簡易な固定値です(`isMatchOver`)。西入・南入等の詳細ルールを反映する場合は要調整。

## ディレクトリ構成

```
src/
  index.ts        Worker本体(API・WS振り分け・静的配信)
  GameRoom.ts      対局用 Durable Object
  Lobby.ts         オンライン人数カウント用 Durable Object
  mahjong/
    tiles.ts       牌定義・山構築・ドラ計算
    words.ts       単語辞書によるアガリ/鳴き判定
    score.ts       符・飜・点数計算
  db/
    schema.sql     D1スキーマ
    seed_words.sql 単語サンプル
public/
  login.html / register.html / xiama/home.html / xiama/room.html / xiama/table.html
  (index.html は本プロジェクト外で別途用意される想定のため含めていません)
  css/, js/
```

## 注意: index.html について

`index.html` は本プロジェクトでは意図的に含めていません(別用途で使用するため)。
ログイン成功後、`?redirect=` の指定がない場合は `/index.html` に遷移する実装になっているので、
別途配置する `index.html` 側で、未ログイン時に `login.html` へ誘導する処理などを実装してください。
